# Agent instructions

Follow best practices. Ask for approval before big changes.

## Agent skills

### Issue tracker

Track issues and specs as local Markdown under `.scratch/<feature>/`.
Read `docs/agents/issue-tracker.md` before working with tickets.

### Triage labels

Use the default five triage roles.
Read `docs/agents/triage-labels.md` before triaging issues.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`.
Read `docs/agents/domain.md` before exploring the codebase.
