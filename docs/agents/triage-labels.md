# Triage labels

For local issues, record these role strings in the `Status:` line.

| Role | Status string | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate |
| needs-info | needs-info | Waiting on reporter information |
| ready-for-agent | ready-for-agent | Fully specified; ready for an autonomous agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Wayfinder's `claimed` and `resolved` workflow states are defined in
`issue-tracker.md`; they are separate from these triage roles.
